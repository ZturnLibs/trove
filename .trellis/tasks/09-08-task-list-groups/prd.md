# 任务分组：分组 → 清单两级结构

## Goal

为 Trove 的任务引入「分组（Group）→ 清单（List）」两级归属结构，让个人任务与公司工作任务可以分开管理、按需聚焦。解决当前所有任务混在收件箱、无法区分工作与个人的问题。

## 现状调研（research notes）

- 详见 `research/codebase-survey.md`（含精确挂点 file:line）。
- 清单机制（`task_lists`，每任务必属一个清单）已存在，但入口只有任务页内一个下拉框；侧边栏（今日/收件箱/任务/记忆/剪切板）完全看不到清单。
- 实测用户数据库：仅收件箱一个清单，78 个任务全部堆积（18 todo / 60 completed），标签数为 0——分组能力从未被用起来，主要症结是入口太深、没有分层。
- `docs/ui-layout-interaction.md` 早已设想 `全部 | 收件箱 | 工作 | 个人` 的清单页签，本次落地并升级为两级。
- 下一个迁移编号为 `0023`；schema 断言当前 22。

## Requirements

### 结构（已确认：分组 + 清单两级）

- 新实体「分组」：侧边栏「任务」区内呈现 分组 → 清单 两级；组内可挂多个清单。
- 清单最多属于一个分组，也可不属于任何分组（未分组清单直接平铺在任务区下）。
- **收件箱固定顶部，不可归组**（捕获桶不参与归类）。
- 收件箱仍是独立顶级导航项（现状不变）。

### 分组生命周期（已确认：全量用户管理）

- 新建：侧边栏任务区 ➕ / 右键菜单。
- 重命名：右键 → 行内编辑。
- 排序：拖拽上下调整（清单同理；清单可拖入/拖出分组）。
- **删除分组 = 解散**：组内清单回到未分组，任务一律不动；支持撤销。不做级联删除。
- 清单本身的新建/重命名/删除沿用现有能力（任务去向三选一：移回收件箱/归档/彻底删除）。

### 侧边栏（已确认）

- 分组行：点击名称 → 任务页过滤出该组全部任务；点击箭头 → 折叠/展开（状态本地记忆）。
- 清单行：点击 → 任务页按清单过滤（接通现有但被忽略的 `/tasks/:listId` 路由）。
- 每行显示未完成任务数徽标。

### 今日页（已确认：过滤 chips）

- 今日页顶部加过滤 chips：`全部 | 各分组`（含「未分组」）。
- 五个区块（今日重点/等待跟进/逾期/提醒/今日任务/今日已完成）统一应用过滤。
- 选择本地记忆；默认「全部」。
- 托盘今日弹窗 v1 不动（保持显示全部）。

### 任务页

- 筛选下拉支持按分组过滤；「全部」视图新增「按清单分区显示」开关（复用现有粘性分组头）。
- 「移动到清单」入口（详情面板/右键）按 分组→清单 分层展示。

### 捕获入口

- 快速捕获（⌘⌥Space）默认仍进收件箱；提供目标清单选择器（按分组分层）。
- 任务页新建任务落在当前选中清单/过滤上下文（现状语义延续）。

### 引导

- 任务页一次性空状态引导（localStorage 标记，不弹窗）：无任何自定义分组时提示「一键创建 工作 / 个人 分组」。

### 明确不做（v1）

- 分组/清单的颜色与图标；记忆/剪切板模块的分组；托盘跟随过滤；NL 捕获按语法路由清单。
