# 对 task 支持子任务

## Goal

为 Trove 的任务（task）增加「子任务」能力。当前任务模型是扁平的：`tasks` 表没有父子关系；已有的 `task_checklist_items`（v2.0 检查项）只是轻量内容条目，不是完整任务。

> 路线图 `docs/development-roadmap.md` 的「暂不包含」清单中列出了「多层子任务、任务依赖和附件」，本次实现其中「子任务」部分。

## 现状调研（research notes）

- `tasks` 表结构：`id, title, notes, status(todo/completed/archived), priority, list_id, due_date, due_time, completed_at, sort_order, created_at, updated_at, revision, deleted_at`，无 `parent_id`。
- `task_checklist_items`（v2.0 slice 6）：`task_id, content, checked, sort_order`，单层，最多 50 条，完成任务后冻结只读。检查项不是完整任务。
- 后端：`src-tauri/src/domain/task.rs`（领域模型）、`src-tauri/src/application/tasks.rs`（TaskService）、`src-tauri/src/commands/mod.rs`（IPC 命令）。
- 前端：`src/features/tasks/TasksPage.tsx`（列表）、`src/design-system/patterns/TaskDetailPanel.tsx`（详情，含 `ChecklistSection`）、`src/design-system/patterns/TaskRow.tsx`（行）。
- IPC 绑定：`src/ipc/client.ts`。
- 迁移文件：`src-tauri/migrations/00XX_*.sql`，下一个编号为 `0022`。

## Requirements

### 方向（已确认）

- **A. 真·嵌套任务**：在 `tasks` 表加 `parent_id`，子任务是完整任务（有自己的状态/优先级/截止日期/标签/检查项/提醒等）。
- **B. 多层嵌套（不限层数）**：子任务还可以有子任务，形成树状结构；数据模型用 `parent_id`（邻接表），查询/UI 需要递归。
- **完成聚合策略做成用户可配置项**（三个策略：自动完成 / 不自动仅进度 / 父完成时级联子任务）：
  - 默认：所有子任务完成 → 父任务自动标记完成；父任务完成时级联完成未完成的子任务。
  - 配置项允许用户关闭上述行为（退化为仅展示进度）。
  - **配置粒度：全局配置**（设置页一个「子任务」区块，两个开关），不做每任务覆盖。

### 完成聚合规则（默认配置下）

- **向上聚合（双向）**：
  - 所有子任务完成 → 父任务自动标记完成。
  - 子任务取消完成 → 父任务恢复为未完成。
- **向下级联（双向）**：
  - 父任务完成时 → 级联完成所有未完成的子任务。
  - 父任务取消完成时 → 子任务一起恢复为未完成。
- 两个开关关闭后：仅展示进度（不自动完成 / 不级联 / 不反向）。

### 展示方式（已确认：A）

- **列表视图树形展开**：TasksPage 中，有子任务的任务显示展开/折叠箭头，展开后子任务以缩进形式显示（可嵌套多层），可直接勾选完成、点击进入详情；支持拖拽排序。
- **详情面板子任务区**：TaskDetailPanel 中新增「子任务」区块，可添加/编辑/排序/删除子任务，可点进子任务详情。

### 创建子任务（已确认：A + C）

- **A. 详情面板输入添加**：详情面板「子任务」区块提供输入框直接添加（类似检查项，回车保存）。
- **C. 拖拽归巢**：列表视图中把已有任务拖到另一个任务上（drop 到任务上）→ 变成其子任务；同时支持从父任务下拖出（提升为普通任务）。

### 删除/归档语义（已确认：C）

- **删除父任务时提供处置选项**（类似现有清单删除的确认交互）：
  - 级联删除：删除父任务及所有后代子任务。
  - 仅删除父任务：子任务提升为顶层任务（parent_id 置空）。
- **归档**：父任务归档时后代级联归档（保持一致）。

### 子任务与现有视图（已确认：A）

- 子任务是完整任务，独立参与一切视图：今日、搜索、智能列表、提醒、托盘、CLI、CSV 等。
- 列表视图（TasksPage）递归查询子任务并以树形展示；其他视图自然包含子任务（不特殊过滤）。

### 列表拖拽与排序（已确认）

- **拖到任务上（目标高亮）→ 成为其子任务**（归巢）。
- **拖到任务间隙 → 同一父节点内重排**（兄弟间换序，保持当前层级）。
- 跨层级移动统一通过「拖到任务上归巢」实现。
- **归巢后保留子任务原清单（list_id 不变）**：父任务与子任务可分属不同清单，列表展示时树形聚合。

### 展开状态（已确认：B 数据库持久化）

- 树形展开/折叠状态持久化到数据库（tasks 表加字段或单独状态表，通过 IPC 读写），应用重启后保持。
- 具体存储方案在 design.md 中定。

### 收尾确认

- **父任务行显示子任务进度**（如 `2/5`，类似现有 ChecklistBadge）。
- **嵌套深度上限 5 层**：超过时禁止再嵌套，提示用户（避免 UI 失控）。
- 不做：任务依赖、附件（路线图中另外两项）。
