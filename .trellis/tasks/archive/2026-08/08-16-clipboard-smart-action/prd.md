# 剪贴板 → 行动智能转化

## Goal

对标 Maccy「OCR 后可直接用」与 Obsidian 插件「捕获→任务」：让剪切板从被动存档升级为主动助理，全程本地、可关闭。

## 对标差距

| 竞品能力 | Trove 现状 |
| --- | --- |
| Maccy OCR 结果一键粘贴 | 有 OCR 搜索，无行动气泡 |
| 复制 URL/代码/日期自动识别 | 无 kind 分类 |
| 与当前任务关联建议 | 有 EntityLink 手动关联，无自动建议 |

## Requirements

1. **类型识别**：新条目轻量分类 URL/邮箱/电话/日期/代码/错误信息/普通文本 → `kind_hint`
2. **行动气泡**：列表项按 kind 显示「存记忆 / 新建任务 / 关联任务 / 复制」
3. **NL 联动**：含日期文本时用现有 NL 解析生成任务草稿预览
4. **相似关联**：复制内容与活跃任务标题/正文相似时建议关联（本地字符串相似度，无远程 AI）
5. **代码视图**：`kind_hint=code` 可筛选

## Acceptance Criteria

- [ ] 复制含 URL 的文本后 3 秒内出现对应行动气泡
- [ ] 识别规则本地执行；设置项可关闭智能行动
- [ ] 转任务/转记忆/EntityLink 与现有流程一致，不重复创建
- [ ] 误分类不影响条目保存与搜索

## 复杂度

**Medium** — 无新表必需（`kind_hint` 字段可选）；规则引擎可 PRD-only 启动。
