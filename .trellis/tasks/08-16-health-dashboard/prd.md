# 工作台健康仪表盘

## Goal

补齐「本地优先 = 可感知可信」差距：用户一屏看清备份、存储、提醒遵守率、任务/收件箱积压，对标 Maccy 透明安全模型与 HelixNotes 数据可控叙事。

## 对标差距

| 竞品能力 | Trove 现状 |
| --- | --- |
| 备份/存储可见 | `backup_status` IPC 已有，**无 UI** |
| TickTick 统计页 | 无 |
| 提醒按时率 | 无聚合 |

## Requirements

1. **页面**：设置区或独立 `/health` 入口
2. **备份**：上次成功/失败时间、占用、轮转数（接 `backup_status`）
3. **存储**：DB / assets / 缩略图占用分布
4. **提醒**：近 7/30 天按时完成 / 贪睡 / 错过比例
5. **任务**：收件箱积压天数、长期未处理数、完成趋势（可选简单曲线）
6. **剪切板**：保留余量、收藏占比
7. **原则**：数字由确定性 SQL 产生；**禁止**评价性效率结论

## Acceptance Criteria

- [ ] 备份状态与设置页手动备份结果一致
- [ ] 存储数字与磁盘实际占用误差可接受（文档说明统计口径）
- [ ] 提醒统计与 scheduler 行为一致（含时区边界单测）
- [ ] 页面加载 < 500ms（万级数据下依赖已有分页/聚合索引）

## 复杂度

**Medium** — 新增若干聚合命令 + 前端一页；可与 weekly-review 共享查询层。
