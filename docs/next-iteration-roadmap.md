# 下一阶段路线图：v1.3 及创新功能

本文档规划 `v1.2` 收尾之后的演进路线，并把每项规划拆解为可勾选、可验收的 todo，作为 Trellis task 的直接来源。

与既有文档的关系：

- [第一版开发规划](./development-roadmap.md)：`v1.0`（阶段 0–5）已完成阶段拆分，**历史性文档，不再修改**。
- [第一版之后的迭代详细设计](./post-v1-iteration-design.md)：`v1.1`–`v2.0` 的设计原则、数据影响与验收标准，**作为本文档的设计依据**。
- 本文档：在上述设计基础上，结合 2026-08 功能差距审计复核与产品创新分析，给出**带 todo、带优先级、带依赖**的执行路线。

进入开发前，每条 todo 仍需按 [workflow](../.trellis/workflow.md) 走 PRD + research 流程，本文档只冻结范围与优先级。

## 4. `v1.2.1`：收尾与可靠性（短期 todo）

目标：清掉仅剩的体验硬伤与正确性问题，为数据量增长和跨平台一致性兜底。所有项**后端多已就绪或改动可控**，适合作为下一轮 Trellis 批次。

### 4.1 数据层分页（P1）

- [ ] 设计统一分页协议：`{ limit, offset, cursor }`，在 `TaskQuery` / `MemoryQuery` / `ClipboardQuery` 一致落地。
- [ ] 后端 `query_tasks` / `memory_query` 默认分页（如 limit=200），返回 `{ items, total, hasMore }`。
- [ ] 前端列表接入无限滚动或"加载更多"，避免一次性渲染全部。
- [ ] 搜索/智能列表沿用同一协议，保证筛选结果一致。
- **验收**：万级数据下列表首屏 < 200ms，滚动加载无重复无遗漏；筛选前后总数一致。
- **依赖**：无新表；`tasks.rs:524-592`、`memories.rs:140-175`。

### 4.2 周期提醒 UI 补全（P2）

- [ ] `TaskDetailPanel`、`TodayPage`、`QuickWindow` 的提醒创建处，把 `recurring: boolean` 升级为完整 `RecurrenceRule` 选择器（每天 / 工作日 / 每周 N / 每月 D / 每隔 N 天）。
- [ ] 选择器与现有 NL 解析结果互通（NL 解析后回填到选择器，而非忽略）。
- [ ] 周期任务详情面板支持修改 `recurrence`（`UpdateTaskInput.recurrence` 已就绪）。
- **验收**：UI 可设置 weekly/monthly/weekdays 且与 NL 路径结果一致；改周期后下一实例按新规则生成。
- **依赖**：`RecurrenceRule` 类型已存在（`client.ts:191`）。

### 4.3 Windows OCR（P2）

- [ ] 调研 Windows 本地 OCR 方案（Windows.Media.Ocr / Tesseract / 平台差异）。
- [ ] `platform/ocr.rs` 非 macOS 分支接入真实实现，替代当前返回空文本的占位。
- [ ] 移除/调整降级文案，恢复 Windows 图片剪贴板可搜索能力。
- **验收**：Windows 上复制图片后可通过 OCR 文字命中；识别在本地完成、断网可用。
- **依赖**：`post-v1` §6.3 OCR 设计原则（本地、可重建、失败不影响图片保存）。

### 4.4 自定义清单删除/重命名（P3）

- [ ] 新增 `task_list_update`（重命名）、`task_list_delete`（软删除，受引用保护）命令。
- [ ] 删除前校验：清单内仍有未完成任务时提示「移动到 / 归档 / 强制删除」。
- [ ] TasksPage 清单区接入右键菜单（重命名 / 删除）。
- **验收**：误建清单可清理；删除不产生孤儿任务；软删除可被撤销栈恢复。

### 4.5 任务页内搜索（P3）

- [ ] TasksPage 顶部加标题/说明搜索框，复用 `query_tasks` 的关键词匹配。
- [ ] 搜索态与现有清单/状态/优先级/标签筛选可叠加。
- **验收**：任务页内不打开全局面板即可定位任务。

### 4.6 搜索筛选维度（P3）

- [ ] `ClipboardQuery` 增加 `sourceApp`、`dateFrom/dateTo` 筛选。
- [ ] ClipboardPage 搜索区加来源应用下拉与时间范围快捷选项。
- **验收**：可按"来自微信、最近 7 天"等组合找回剪切板条目。

### 4.7 跨版本测试加固（P2）

- [ ] 为提醒调度链路（`scheduler.rs`）补单测：错过补发、周期生成、时区/DST 边界。

## 5. 创新功能（差异化 todo）

以下方向契合 Trove「本地优先 + 任务/记忆/剪贴板三合一」的定位，强调**复用已有数据、纯本地、低隐私风险**。每项进入开发前需确认高频场景证据。

### 5.1 🌟 剪贴板 → 行动的智能转化

把剪切板从「被动存档」升级为「主动助理」，复用已有的来源应用 + OCR + NL 解析。

- [ ] **类型识别**：对剪切板新条目做轻量分类（URL / 邮箱 / 电话 / 日期 / 代码 / 错误信息 / 普通文本），落库到 `clipboard.kind_hint`。
- [ ] **行动气泡**：列表项根据 `kind_hint` 浮现快捷动作（保存为记忆 / 新建任务 / 关联到当前任务 / 复制）。
- [ ] **当前任务关联**：复制内容与活跃任务标题/正文相似时，建议「关联到 XXX」。
- [ ] **代码片段视图**：`kind_hint=code` 进入专属筛选视图。
- [ ] **NL 联动**：复制含日期/地址文本时，用现有 NL 解析生成任务草稿预览。
- **验收**：复制报错文本 3 秒内出现「保存为记忆/新建排查任务」气泡；全程本地、可关闭。
- **依赖**：剪切板轮询、NL 解析（已就绪）、EntityLink（已就绪）。
- **隐私**：识别规则本地执行；默认不开远程 AI。

### 5.2 🌟 工作台健康仪表盘

把已有确定性数据变成可感知的工作节奏信号，是 v1.3 复盘功能的数据基础。

- [ ] 新增 `/health` 页面（设置区入口），聚合：
  - [ ] 备份状态（上次成功/失败时间、占用、剩余轮转数）。
  - [ ] 存储占用分布（DB / assets / 缩略图）。
  - [ ] 提醒遵守率（按时完成 / 贪睡 / 错过，近 7/30 天）。
  - [ ] 任务积压曲线、收件箱积压天数、长期未处理任务数。
  - [ ] 剪贴板保留余量、收藏占比。
- [ ] 所有数字由确定性 SQL 查询产生，不涉及评价性结论。
- **验收**：一屏看清「备份是否健康 / 积压是否增长 / 提醒是否被忽略」。
- **依赖**：复用 `app_health`、`backup_status`、新增若干聚合查询命令。

### 5.3 🌟 记忆轻量关联（不造知识图谱的双链）

让记忆从「散落笔记」变成「网络」，复用 EntityLink + 搜索索引。

- [ ] 记忆正文支持 `[[标题]]` 语法，保存时解析并建立 `EntityLink(type=mention)`。
- [ ] 详情页「相关记忆」区：按共同标签 / 共同 EntityLink / 正文关键词重合聚类（top 5）。
- [ ] 触发词记忆被引用时累加 `useCount`，影响排序。
- [ ] 反向链接视图：在记忆详情展示「谁引用了我」。
- **验收**：编辑 `[[A]]` 后，A 的详情页出现反向链接；相关记忆推荐可一键确认建链。
- **依赖**：`EntityLink`（已就绪）、搜索索引扩展到记忆正文。
- **边界**：不做知识图谱可视化、不做块级引用。

### 5.4 🌟 今日智能排序建议

v1.3「今日重点」的轻量预览版，不碰日历，纯本地排序。

- [ ] 排序算法（确定性）：综合截止时间、优先级、历史延期次数、提醒时间，输出建议顺序。
- [ ] 每项附「一句话理由」（如「今天到期」「已延期 2 次」）。
- [ ] 今日页提供「采纳建议顺序」按钮，用户可手动调整后再固定。
- [ ] 候选与今日重点解耦：建议只影响顺序，不自动改归属/状态。
- **验收**：进入今日页可见建议顺序与理由；采纳后可继续拖拽调整。
- **依赖**：`Task.due_*` / `priority` / 历史延期统计（需轻量埋点）。

### 5.5 🌟 URL Scheme 提前切片（v1.4 低成本开门）

数据模型已稳定，先开放只读 + 创建类，立刻可被 Raycast/Alfred/浏览器调用。

- [ ] 注册 `trove://` scheme（`tauri.conf.json`）。
- [ ] 支持动作：`trove://today`、`trove://inbox`、`trove://search?q=`、`trove://create?type=task&...`。
- [ ] 创建类链接强制预览确认（遵循 `post-v1` §8.3 安全要求）。
- [ ] 参数长度/编码白名单校验，禁止执行系统命令或读取任意文件。
- [ ] 文档：发布 URL Scheme 清单供社区使用。
- **验收**：浏览器书签 `trove://create?type=task&title=...` 可弹确认后创建任务。
- **依赖**：无新表；与 v1.4「统一动作层」对齐，避免重复实现。

### 5.6 🌟 专注模式 + 本地分心洞察

v1.3 专注模式的增值版，纯本地、可关闭。

- [ ] 专注会话：选定任务 → 倒计时 → 结束提醒（不强制停止）。
- [ ] 专注期间轻量记录前台应用切换（仅应用名 + 时间戳，**不存正文/标题**）。
- [ ] 结束摘要：「25 分钟内切走 4 次，主要去了 微信/浏览器」。
- [ ] 设置项：总开关、是否记录应用切换、数据可一键清空。
- **验收**：专注异常退出不把任务标记完成；分心数据完全本地、可清空。
- **隐私**：macOS Accessibility 权限需显式申请并说明用途；拒绝则降级为纯计时。
- **边界**：不做录屏、不做跨设备同步、不做效率评分。

### 5.7 🌟 每周复盘卡片（轻量可视化）

v1.3 每周回顾的可视化形态，确定性数字 + 可选 AI 摘要。

- [ ] 周报卡片组件（纯统计）：完成/取消/延期数、延期 ≥2 次的"卡住"任务、提醒按时率折线、剪贴板收藏 Top。
- [ ] 一键处理入口：逾期任务、收件箱积压、等待跟进事项。
- [ ] 可选 AI 摘要：把统计数字组织成一段中文（遵循 `post-v1` §9.3：数字由查询产生，模型只组织文字）。
- [ ] 任务名可点击跳转原始条目。
- **验收**：每周回顾一屏看完关键信号；不生成绩效分数。
- **依赖**：5.2 健康仪表盘的部分聚合查询可复用。

## 8. 版本进入与退出

进入每个版本/切片前（遵循 `post-v1` §12）：

1. 从上一版本反馈中确认 3 个主要使用阻力。
2. 将候选 todo 对应到记录/切换/找回/维护/可信成本。
3. 冻结本期「必须完成」与「明确不做」范围。
4. 确认数据迁移、权限变化与降级方案。
5. 为核心流程准备验收用例。

退出时检查：版本目标中的**完整用户流程**可用（而非单个控件完成）；新功能未降低提醒与数据可靠性；新增数据可导出/备份/恢复/重建。
