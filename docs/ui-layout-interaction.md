# 第一版 UI 布局与交互设计

## 1. 文档目的

定义 `v1.0` 桌面端的整体信息架构、窗口布局、页面骨架和核心交互，作为前端实现与阶段验收的视觉/交互基线。

功能范围仍以[第一版开发规划](./development-roadmap.md)为准；技术约束以[技术设计](./technical-design.md)为准。本文不覆盖 `v1.1+` 的命令面板、菜单栏今日面板等能力，但会预留扩展位。

## 2. 设计原则

1. **桌面工作台，而非营销页**：紧凑密度、稳定行高、键盘优先；首屏只服务“今天要做什么”。
2. **一窗一主职**：主窗口负责浏览与整理；快捷窗口负责捕获、搜索与剪切板复用；托盘只做短动作入口。
3. **列表主、详情次**：默认用主从分栏；不把详情做成层层堆叠的卡片墙。
4. **类型边界清晰**：任务、提醒、记忆、剪切板视觉可区分，转换操作用明确动作完成，不混成一种通用条目。
5. **权限与降级可见**：通知、辅助功能等缺失时，界面给出可操作的降级路径，不静默失败。
6. **关闭不等于退出**：关闭主窗口隐藏到托盘；仅托盘“退出”结束进程。

## 3. 视觉方向（v1.0）

### 3.1 气质

冷静、工具感、偏编辑器/邮件客户端密度。避免营销风大留白、多层阴影和圆角胶囊堆砌。

### 3.2 令牌约束（与技术设计对齐）

| 类别 | 约定 |
| --- | --- |
| 主题 | `system` / `light` / `dark`，根节点 `data-theme` |
| 颜色 | 语义令牌：`surface`、`surface-raised`、`foreground`、`muted`、`accent`、`danger` |
| 圆角 | 控件 ≤ 6px，面板 ≤ 8px；页面区域不做多层卡片包裹 |
| 字号 | 正文约 13–14px；侧栏与列表次要信息更小；标题克制 |
| 行高 | 任务行默认 32–36px；可选“舒适”密度，默认紧凑 |
| 强调色 | 单一 accent；优先级用字重/图标/小标记，不用多色彩虹 |

### 3.3 类型色标（轻量）

仅用于结果类型点、筛选芯片与图标，不整行染色：

| 类型 | 识别 |
| --- | --- |
| 任务 | 勾选框 + “任务”标签色 |
| 提醒 | 时钟图标 + “提醒” |
| 记忆 | 书签/便签图标 + “记忆” |
| 剪切板 | 剪贴板图标 + “剪贴板” |

## 4. 应用外壳与窗口模型

### 4.1 窗口职责

```text
┌─────────────────────────────────────────────────────────┐
│  main（完整工作台）                                       │
│  浏览、整理、详情编辑、设置、备份入口                      │
└─────────────────────────────────────────────────────────┘

┌──────────────────────────────┐
│  quick（浮层）                │
│  mode: capture | search | clip│
│  预创建、快捷键唤起、失焦可隐   │
└──────────────────────────────┘

  tray（原生菜单）
  打开主窗 / 快速记录 / 剪切板 / 暂停采集 / 下一条提醒 / 设置 / 退出
```

| 窗口 | 默认尺寸（建议） | 行为 |
| --- | --- | --- |
| `main` | 1080×720，最小 880×560 | 关闭 = 隐藏；记住位置与尺寸 |
| `quick` | 560×420（capture/search）；剪切板可加高至 520 | 预创建隐藏；唤起后聚焦输入；按 mode 决定失焦是否自动隐藏 |

### 4.2 全局快捷键（默认，均可改）

| 动作 | 建议默认（macOS / Windows） |
| --- | --- |
| 快速记录（capture） | `⌘⇧Space` / `Ctrl+Shift+Space` |
| 统一搜索（search） | `⌘⇧F` / `Ctrl+Shift+F` |
| 剪切板历史（clip） | `⌘⇧V` / `Ctrl+Shift+V` |
| 打开/聚焦主窗口 | `⌘⇧A` / `Ctrl+Shift+A`（可关） |

冲突时：设置页提示冲突应用或“已被占用”，允许改键与恢复默认。完整键位表与设置交互见[快捷键一览](./keyboard-shortcuts.md)；空状态与权限文案见[空状态与权限文案](./empty-states-and-permissions.md)。

### 4.3 托盘交互

- 左键（或平台惯例单击）：打开主窗口或展示原生菜单（macOS 优先菜单；Windows 左键开主窗、右键菜单，阶段 0 按平台验证后锁定）。
- 菜单项保持短文本；“下一条提醒”仅一行摘要，点击打开对应详情（经主窗或 quick，见 §9）。
- “暂停/恢复剪切板记录”立即切换，并在菜单文案反映当前状态。
- 完整菜单栏、托盘项 ID、上下文菜单与启用规则见[应用菜单设计](./app-menu-design.md)。

### 4.4 系统通知交互

通知操作：完成、稍后（10 分钟 / 1 小时 / 明天）、打开。

- “打开”：若主窗隐藏则显示并导航到对应任务/提醒；若已在前台则仅路由跳转。
- 稍后与完成不强制打开窗口；成功后可短暂 toast（仅主窗可见时）或静默。

## 5. 信息架构

### 5.1 一级导航（主窗口）

固定五个一级入口 + 底部设置：

```text
今日        ← 默认首页
收件箱
任务
记忆
剪切板
────────
设置
```

提醒**不是**一级导航。独立提醒出现在：今日时间区块、任务详情内的提醒列表、统一搜索结果。

### 5.2 路由结构（建议）

```text
/today
/inbox
/tasks                      ← 默认某清单或“全部”
/tasks/:listId
/tasks/item/:taskId         ← 可选深链；也可用 query ?id=
/memory
/memory/:memoryId
/clipboard
/settings
/settings/shortcuts
/settings/clipboard
/settings/backup
/settings/about
```

搜索不占用一级导航；主窗内用顶栏搜索框打开命令式结果浮层，或全局快捷键走 `quick` search mode。

### 5.3 实体转换地图

```text
剪切板 ──保存为记忆──► 记忆
剪切板 ──转为任务──► 任务（收件箱）
记忆   ──转为任务──► 任务（原记忆默认保留）
任务   ──可挂提醒──► 提醒 occurrence
独立提醒 ◄──快速记录── 用户
```

转换后：toast 提供“查看”链接；统一搜索可同时命中源与目标（若仍存在）。

## 6. 主窗口布局

### 6.1 整体骨架

三区结构：**侧栏 | 主列表 | 详情**。窄宽时详情改为右侧抽屉或覆盖层，不断开侧栏。

```text
┌──────┬────────────────────────────┬──────────────────────┐
│ Logo │  顶栏：标题 / 筛选 / 搜索 / + │                      │
│      ├────────────────────────────┤      详情面板         │
│ 今日 │                            │  标题、字段、操作      │
│ 收件 │        列表区域             │  提醒、标签、说明      │
│ 任务 │        （可滚动）            │                      │
│ 记忆 │                            │                      │
│ 剪贴 │                            │                      │
│      │                            │                      │
│ ──── │                            │                      │
│ 设置 │                            │                      │
└──────┴────────────────────────────┴──────────────────────┘
  ~200px         flex 1 最小 360px            ~360px（可拖拽）
```

### 6.2 侧栏

| 元素 | 行为 |
| --- | --- |
| 应用名 / 图标 | 点击回今日；可拖拽窗口（`-webkit-app-region: drag`） |
| 导航项 | 图标 + 文案；选中态用 `surface-raised` + 左侧 accent 条或字重 |
| 角标 | 收件箱未整理数；今日逾期数（仅数字，不抢主色） |
| 设置 | 钉在侧栏底部，与业务导航分离 |

侧栏宽度固定约 200px；不提供折叠为纯图标模式（`v1.1` 可再议），避免双平台首版复杂度。

### 6.3 顶栏（随路由变化）

统一模式：

1. **页面标题**（左）
2. **视图控件**（中左）：清单切换、分段筛选、排序
3. **搜索**（中右）：聚焦后展开结果；`⌘K` 在主窗内聚焦此框（与全局 search 快捷键可并存，设置中说明）
4. **主操作**（右）：`新建` 下拉（任务 / 提醒 / 记忆），默认当前模块对应类型

### 6.4 列表与详情联动

- 单击列表行：选中并填充详情面板（不新开窗）。
- 双击或 `Enter`：同单击；已选中时 `Enter` 聚焦详情标题编辑。
- `⌘/Ctrl + Enter`：完成任务 / 收藏剪切板等主操作（随类型变化）。
- 删除、归档：详情内或行内更多菜单；破坏性操作二次确认。
- 无选中时：详情区显示当前页空状态说明或“选择一项查看详情”。
- 多选（`v1.0`）：仅支持 Shift/⌘ 多选后的批量完成、归档、删除；不做复杂批量改字段。

### 6.5 详情面板通用结构

```text
┌─ 类型徽章 · 更新时间 ─────────── ⋯ 更多 ┐
│ 标题（可编辑）                            │
│ 主字段区（日期、清单、优先级、标签…）      │
│ 正文 / 说明（可滚动）                     │
│ 附属块（提醒列表、来源链接、转换记录）      │
├─────────────────────────────────────────┤
│ 次要操作…              主操作（完成/保存） │
└─────────────────────────────────────────┘
```

- 普通字段：短延迟自动保存或失焦保存，同一模块内保持一致。
- 提醒规则、删除、清空：显式确认，等待后端成功。
- 错误时保留草稿，顶部或字段旁显示可重试错误。

## 7. 各一级页面布局

### 7.1 今日 `/today`

**目标**：手动圈定今日重点，处理等待跟进、逾期、今天到期与提醒。

```text
顶栏：今日 · 日期文案     [每日收尾] [专注*] [全部提醒]  [+]
                              *选中项在今日重点时显示
────────────────────────────────────────────────────────────
[ 昨日重点结转横幅 ]  （有未完成时，可加入 / 忽略）
[ 专注异常退出横幅 ]  （上次会话未正常结束，启动时一次性提示）

列表（分组，组头粘性）：
  ▸ 今日重点（N）      ← 始终置顶；空时保留最小高度与提示
      □ 任务行…        ← 左侧 accent 竖条；区内可拖拽排序
  ▸ 等待跟进（N）      ← follow-up 到期；无项时隐藏
      ⏸ 任务行 + 结束等待 / 继续等待 / 完成
  ▸ 逾期（N）          ← muted「逾期」小字，无羞辱式徽章
      □ 任务行…
  ▸ 今日提醒（N）
      ⏰ 提醒行…
  ▸ 今日任务（N）
      □ 任务行…        ← 可拖入今日重点区
  ▸ 今日已完成（N）    ← 默认折叠
详情：选中项；任务详情含「推迟显示」「等待事项」分区
```

交互要点：

- 分组顺序：今日重点 → 等待跟进 → 逾期 → 今日提醒 → 今日任务 → 今日已完成。
- **今日重点**与截止日期独立：加入重点不改 due；拖入/拖出仅增删 `daily_focus`。
- **推迟显示**（`availableAt`）与**延期**（改 `dueDate`）分区展示；推迟任务不进活跃列表，搜索与「已推迟」视图可找回。
- **等待**任务不进收件箱/今日 due；跟进日到期出现在「等待跟进」区。
- 完成任务后若在该日重点中，自动移出重点；可撤销（recent-actions）。
- 超过 5 项重点时温和提示（可关闭）；昨日未完成重点可结转横幅（忽略写入设置）。
- 超过 5 项重点时温和提示（可关闭）；昨日未完成重点可结转横幅（忽略写入设置）。
- 键盘：`F` 切换重点，`⇧F` 移出重点；`Enter` / `⌘Enter` 进入专注（见[快捷键一览](./keyboard-shortcuts.md) §6.1）。
- **每日收尾**：顶栏入口；今日已有 completed wrap 时显示「今日已收尾 · 查看摘要」（见 §7.1.2）。
- **智能排序建议**（可关闭）：「今日任务」区按截止时刻、优先级、延期次数与今日提醒生成确定性建议序；预览时行下显示理由，「采纳建议顺序」写入 `sort_order`，之后仍可拖拽；不影响今日重点 membership。

#### 7.1.1 专注模式

**目标**：单任务沉浸，可选番茄倒计时；退出时明确任务状态，异常退出不误标记完成。

**入口**：今日重点行 + 顶栏「专注」、任务详情「开始专注」、今日页 `Enter`（已在重点）或 `⌘Enter`（任意待办）。

```text
┌─ 全屏 overlay（主窗内，非新窗口）──────────────────────┐
│ [ Esc 退出专注 ]              [ 25:00 ▼ 计时可选 ]      │
│                                                         │
│  任务标题 · 清单 · 截止 · 优先级                         │
│  ── 说明 ──（只读；编辑需退出后在详情改）                 │
│  ── 相关 ── 记忆 / 附件缩略（最多 5，可展开）           │
│  [ 进展备注 optional ]                                   │
│  [ 保持待办并退出 ]              [ 完成任务 ]            │
└─────────────────────────────────────────────────────────┘
```

交互要点：

- 背景略提亮，无全屏 blur；`Esc` 先确认再退出（默认保持待办）。
- 倒计时可选 15 / 25 / 45 分钟或无；到点系统通知，不锁屏、不自动完成任务；可「稍后 5 分钟」延长本地计时。
- 「完成任务」= `focus_end(completed)` + 任务完成，可撤销（recent-actions）。
- 「保持待办并退出」= `focus_end(keptTodo)`，可选进展备注（默认**不**追加到 task.notes）。
- 进程异常退出：启动时 abandon 未结束会话并横幅提示；`beforeunload` best-effort abandon。
- 新专注开始会自动 abandon 上一个 in_progress 会话。

#### 7.1.2 每日收尾

**目标**：下班前温和处理未完成重点，预览明日与收件箱，记录当日摘要；可跳过、可撤销逐步决策。

**入口**：今日顶栏「每日收尾」；已完成时「今日已收尾 · 查看摘要」（可再次收尾）。

```text
Modal 分步（非全屏）：
  Step 1  今日重点未完成   每项：保留 / 推迟 / 等待 / 完成 / 移出重点
  Step 2  明日预览         只读列表 + 链到任务页
  Step 3  收件箱           计数与预览 + 链到收件箱
  Step 4  当日摘要         完成数、提醒数、重点处理率 →「收尾完成」
```

交互要点：

- Step 1–3 可「跳过此步」；Step 4 不可跳过；**禁止**一键全部延期。
- Step 1 推迟复用 `DeferPicker`，等待为内联表单；每次决策立即调 API + recent-actions。
- 文案中性：「还有 N 项重点未处理 — 选一个对你最合适的动作」。
- `Esc` 退出向导，run 未完成；「收尾完成」写入 `daily_wrap_runs` 与 summary JSON。
- 完成后顶栏切换为摘要入口；摘要含决策计数与当日数字。

#### 7.1.3 每周回顾

**入口**：今日顶栏「每周回顾」、设置「工作节奏 → 打开每周回顾」、路由 `/weekly-review`。

一屏 7 类信号卡片（确定性 SQL，无效率评分）：

| 卡片 | 含义 |
| --- | --- |
| 未整理收件箱 | inbox todo |
| 逾期任务 | due &lt; today |
| 等待跟进 | follow-up 到期 |
| 长期未更新 | 14 天未改的活跃 todo |
| 近 7 天已完成 | completed_since |
| 即将到来周期提醒 | 7 天内 next_fire |
| 大体积未收藏剪切板 | ≥ 500 KB 图片 |

每项可点选打开详情侧栏；待办可快捷「完成」；剪切板可「收藏」。底部「完成本次回顾」写入 `ReviewSession`；再次进入显示距上次完成天数。

#### 7.1.4 健康仪表盘

**入口**：设置「工作节奏 → 打开健康仪表盘」、路由 `/health`。

一屏聚合本地数据健康信号（确定性 SQL，**禁止**效率评分）：

| 区块 | 含义 |
| --- | --- |
| 备份 | 轮转数、最近成功时间、目录占用（与 `backup_status` 一致） |
| 存储 | 数据库 + WAL、assets 表 byte_size、缩略图目录、备份目录分布；健康页可手动「清理可回收资源」（与 assets GC 规则一致） |
| 区域截图 | 默认 `⌘⇧6` / `Ctrl+Shift+6`（macOS 交互选区）；保存至剪切板历史并走 OCR |
| 文件引用 | 任务/记忆详情可添加本地文件引用（不复制本体）；打开 / Finder 显示 / 重新定位 |
| 提醒遵守率 | 近 7 / 30 天按时完成、贪睡、错过、仍逾期比例 |
| 任务 | 收件箱积压、最久天数、14 天未更新、近 7 天完成趋势 |
| 剪贴板 | 条数 / 上限、剩余额度、收藏占比、保留天数 |

页内「刷新」重新拉取 `health_dashboard_snapshot`；备份管理链至设置页。

### 7.2 收件箱 `/inbox`

**目标**：消化尚未整理的新任务。

```text
顶栏：收件箱 · N 项待整理     [全部整理到…]  [+]
列表：按创建时间倒序（可手动排序）
详情：完整任务字段 + “移到清单” 强调操作
```

- 新任务默认进收件箱；有今日截止日期的同时出现在今日。
- “整理”= 指定清单（可保留标签）；移出后从收件箱消失。
- 空状态：说明可用快捷键快速捕获，并给“新建任务”按钮。

### 7.3 任务 `/tasks`

**目标**：按清单管理全部任务。

```text
侧栏内或列表顶：清单切换
  全部 | 收件箱 | 工作 | 个人 | … | + 新建清单

顶栏：清单名    [状态] [优先级] [标签] [已推迟] [等待中] [排序]   [+]
列表：当前筛选结果
详情：任务全字段 + 推迟显示 / 等待事项 + 提醒子列表 + 周期规则（若有）
```

- 筛选芯片可组合；**已推迟**、**等待中**与智能列表「已推迟」「等待跟进」语义一致；保存视图时一并持久化。
- 智能列表含：明天、未来七天、逾期、高优先级、无日期、最近完成、**已推迟**、**等待跟进**。
- 列表支持拖拽排序（仅当前视图排序值）。
- 周期任务在列表中显示“重复”小标记；详情编辑规则。

### 7.4 记忆 `/memory`

**目标**：短片段的保存、置顶、检索入口之一；轻量双链网络。

```text
顶栏：记忆    [标签] [仅置顶] [含归档]     [+]
列表：置顶区（若有）+ 按更新时间
详情：标题、Markdown 编辑/预览、[[双链]]、反向链接、相关记忆、标签、置顶、转为任务
```

- 正文 `[[标题]]` 保存时解析为 `EntityLink(mention)`；唯一匹配自动建链，歧义/缺失弹出选择（新建 / 关联 / 跳过）。
- **反向链接**：展示引用当前记忆的其他记忆，可点击跳转。
- **相关记忆**：按共同标签、EntityLink、关键词重合推荐 top 5，可一键建链。
- 被引用记忆的 `mentionUseCount` 累加，影响 QuickWindow 快速插入排序。
- 预览禁用原始 HTML；链接外开。
- “转为任务”成功后保留记忆并显示来源关系。

### 7.5 剪切板 `/clipboard`

**目标**：历史浏览、搜索、复用、转换；隐私控制入口明显。

```text
顶栏：剪切板  ● 记录中 | 已暂停     [仅收藏] [代码片段] [搜索]  [暂停] [清空…]
列表：时间倒序 + kind_hint 标签 + 智能行动气泡（可关闭）
行：文本摘要 · 来源应用 · 时间 · 星标 · [存记忆/新建任务/复制…]
详情：全文、智能分类、NL 任务草稿预览、相似任务关联建议、再次复制、转换、删除
```

- 顶栏状态灯：记录中 / 已暂停；与托盘同步。
- **智能行动**（设置可关）：本地规则识别 URL/邮箱/电话/日期/代码/报错 → `kind_hint`；列表行动气泡；含日期文本联动 NL 解析任务草稿；与活跃任务标题/正文 Jaccard 相似度建议关联（`EntityLink`）。
- **代码片段**：`kind_hint=code` 筛选视图。
- 转任务/转记忆通过 `EntityLink(converted_to)` 防重复创建。
- “清空”确认框明确：保留收藏 / 删除范围。
- 未授辅助功能：主按钮为“复制”，旁注“直接粘贴需授权”链到设置。

### 7.6 设置 `/settings`

分组侧栏或锚点列表：

| 分组 | 内容 |
| --- | --- |
| 通用 | 开机启动、关闭主窗行为说明、主题、语言（若有） |
| 快捷键 | 列表、冲突提示、恢复默认 |
| 通知 | 权限状态、测试通知、引导系统设置 |
| 剪切板 | 暂停、智能行动开关、保留天数、数量上限、排除应用、能力边界说明 |
| 数据 | 导出 JSON、导入、备份位置、立即备份、从备份恢复 |
| 关于 | 版本、隐私摘要、开源许可 |

设置页**不使用**三栏详情；用单栏表单 + 右侧说明文字。

## 8. 快捷窗口 `quick`

一个 WebView，三种 mode，顶部品字形或分段控件切换（可用快捷键循环）。

### 8.1 通用壳

```text
┌──────────────────────────────────────────┐
│  [记录] [搜索] [剪切板]          Esc 关闭 │
│  ┌────────────────────────────────────┐  │
│  │ 主输入区                            │  │
│  └────────────────────────────────────┘  │
│  下方：类型选项 / 结果列表 / 历史列表      │
└──────────────────────────────────────────┘
```

- 唤起时按快捷键进入对应 mode，并 `focus` 主输入。
- `Esc`：清空或关闭（有输入时先清空，再按关闭；或统一关闭，设置可选）。
- capture / search：失焦默认隐藏；clip：失焦默认隐藏，但“再次复制”后可立即隐藏以便粘贴。

### 8.2 Capture（快速记录）

```text
类型切换：任务 | 提醒 | 记忆     （Tab 在类型间切换亦可）
主输入：标题（单行）
次级：截止日期/时间（任务、提醒）、清单、优先级（折叠“更多”）
底部：⌘Enter 创建 · Esc 取消
```

- 默认类型 = 任务。
- 创建成功：短暂成功态后隐藏窗口；失败：保留输入。
- `v1.0` 不做自然语言解析；日期用紧凑日期时间控件。

### 8.3 Search（统一搜索）

```text
输入查询
筛选：全部 | 任务 | 提醒 | 记忆 | 剪切板   + 可选标签/状态
结果分组列表：
  任务 (n)
  提醒 (n)
  记忆 (n)
  剪切板 (n)
键盘：↑↓ 选择 · Enter 打开 · ⌘Enter 主操作（完成/复制）
```

- “打开”：任务/记忆/提醒 → 显示主窗并定位；剪切板 → 可留在 quick 详情或复制。
- 空查询：不展示全库；可显示“最近打开/最近修改”有限条（可选，不阻塞首版）。

### 8.4 Clip（剪切板浮层）

```text
搜索框
列表（与主窗同源数据）
选中：Enter 复制并隐藏 · ⌘Enter 尝试直接粘贴
行内快捷：星标、存记忆、转任务
底栏：暂停记录 · 打开主窗剪切板页
```

## 9. 跨窗口导航约定

| 起点 | 动作 | 结果 |
| --- | --- | --- |
| quick 打开任务/记忆 | Enter | 显示 main，路由到实体，选中详情 |
| 通知“打开” | 点击 | 同上 |
| 托盘“快速记录” | 点击 | 显示 quick capture |
| 托盘“剪切板” | 点击 | 显示 quick clip |
| 主窗新建 | 点击 + | 默认同页内创建；按住或下拉可选“在快捷窗口创建” |
| 任意窗数据变更 | 事件 | 另一窗 Query 失效刷新，无正文经事件传递 |

## 10. 核心交互流程

### 10.1 捕获到完成

```text
快捷键 → quick capture → 创建任务（可设明日）
  → 主窗收件箱/今日可见
  → 添加提醒（详情）
  → 到时通知 → 完成 / 稍后
```

### 10.2 剪切板闭环

```text
系统复制 → 历史出现
  → quick clip 搜索 → 再次复制/粘贴
  → 存为记忆 或 转为任务
  → 主窗搜索可找回
```

### 10.3 记忆转任务

```text
记忆详情 → 转为任务 → 确认标题/清单
  → 新任务进收件箱
  → 记忆保留，显示“已转为任务”链接
```

| 范围 | 按键 | 动作 |
| --- | --- | --- |

| 全局 | `⌘N` | 当前模块新建 |
| 全局 | `⌘F` 或 `⌘K` | 聚焦顶栏搜索 |

## 12. 状态设计

### 12.1 空状态

每页统一结构：一句话说明用途 + 一个主操作 + 可选快捷键提示。不使用插画堆砌。

### 12.2 加载

列表首屏用骨架行（固定高度，防跳动）；详情用字段级 skeleton。切换路由时保留侧栏，避免整窗闪白。

### 12.3 错误

- 可重试：列表顶横幅 + 重试。
- 字段校验：贴字段。
- 数据损坏 / 迁移失败：阻塞式全页，提供恢复备份入口（阶段 5）。

### 12.4 权限

| 权限 | UI |
| --- | --- |
| 通知未授权 | 设置与今日顶栏提示；提醒仍可创建，到时无法弹出时说明 |
| 辅助功能未授权 | 剪切板“直接粘贴”降级为复制，设置中引导 |
| 剪切板暂停 | 顶栏与托盘明确“已暂停”，列表仍可浏览历史 |

## 13. 动效（克制）

`v1.0` 仅保留：

1. 快捷窗口显示/隐藏：短 fade + 轻微 scale（尊重“减少动态效果”）。
2. 列表选中与详情切换：内容交叉淡入，时长短。
3. 完成任务：勾选与划线，行移入已完成组可瞬时，不必长动画。

不做：背景光晕、抛物线飞入、页面转场堆叠。

## 14. 响应式与平台

| 宽度 | 布局 |
| --- | --- |
| ≥ 1100px | 侧栏 + 列表 + 详情三栏 |
| 880–1099px | 侧栏 + 列表；详情为右侧 Drawer（≥360px） |
| 主窗最小 880×560 | 低于此不允许（或强制 Drawer） |

- macOS：流量灯区域留出；侧栏顶部为拖拽区。
- Windows：标题栏与 WebView 融合策略在阶段 0 验证；保持同一套内容布局。
- 多显示器：quick 显示在当前焦点屏居中偏上。

## 16. v1.0 明确不做的 UI

- 一级“提醒”或“日历”导航。
- 菜单栏内嵌完整今日 WebView 面板（`v1.1`）。
- 全局命令面板（`v1.1`）。
- 自然语言创建预览条（`v1.1`）。
- 看板、甘特、月历。
- 多列自定义仪表盘。
- 图片剪切板网格（`v1.2`）。

预留：侧栏底部设置之上不放死模块，避免 `v1.1` 智能列表无处安放时可加“智能”分组而不改一级五入口。

## 17. 验收标准（UI/交互）

1. 冷启动进入今日；五入口可键盘 `⌘1`–`⌘5` 切换。
2. 三栏在默认尺寸下可用；缩窄后详情以 Drawer 呈现且不丢选中态。
3. 快捷窗口三种 mode 均可全局唤起，创建/搜索/复制主路径可纯键盘完成。
4. 今日分组顺序固定：今日重点置顶 → 等待跟进（有则显）→ 逾期 → 提醒 → 今日任务 → 已完成。
5. 专注模式可从今日重点或详情进入；退出不误改任务状态；每日收尾 Step 1 无批量延期。
6. 关闭主窗后托盘可再打开；退出仅通过托盘退出。
7. 权限缺失时剪切板与通知路径有明确降级与设置入口。
8. 主题切换 light/dark/system 不改变布局结构。
9. 类型转换均有确认或成功反馈，且可导航到结果实体。
