# 快捷键一览与设置设计

## 1. 文档目的

定稿 `v1.0` / 当前产品线的快捷键目录、作用域、默认可改范围，以及设置页「快捷键」区块的交互。与[应用菜单](./app-menu-design.md)、[UI 布局与交互](./ui-layout-interaction.md)保持同一套键位语义。

展示用符号：macOS 用 `⌘ ⌥ ⇧ ⌃`；Windows / Linux 用 `Ctrl Alt Shift`。设置存储与代码内部使用 `Command+Shift+Space` 这类可解析字符串。

## 2. 作用域分层

| 层级 | 生效条件 | 用户可否改 | 示例 |
| --- | --- | --- | --- |
| **全局** | 应用在后台也生效（已注册成功时） | 可改；冲突可恢复默认 | 快速记录、统一搜索、剪切板、聚焦主窗 |
| **应用菜单加速键** | 应用为前台时 | `v1.x` 随菜单绑定；高级重映射可后置 | `⌘N` 新建任务、`⌘1`–`⌘5` 导航 |
| **窗口局部** | 焦点在 main / quick 且未落入互斥输入态 | 一般不可改；写入帮助一览 | `Esc` 关闭、`↑↓` 选择 |
| **系统编辑** | 焦点在可编辑控件 | 不改，交给系统 | `⌘C` / `⌘V` |

规则：

1. 同一用户意图只对应**一个**可配置项（例如全局「快速记录」）。
2. 菜单栏显示的加速键必须与配置或本文默认表一致。
3. 输入框内优先系统编辑；`Space` 完成任务等局部键在 `contentEditable` / `input` / `textarea` 中**不触发**。
4. 全局键注册失败时：设置页标记冲突/失败；托盘与菜单仍可用。

## 3. 全局快捷键（可配置）

配置字段：`settings.shortcuts.*`（已实现）。

| 配置键 | 意图 | macOS 默认 | Windows 默认 | 动作 |
| --- | --- | --- | --- | --- |
| `quickCapture` | 快速记录 | `⌘⇧Space` | `Ctrl+Shift+Space` | 显示 quick · capture |
| `search` | 统一搜索 / 命令面板 | `⌘⇧F` | `Ctrl+Shift+F` | 显示 quick · search |
| `clipboard` | 剪切板历史 | `⌘⇧V` | `Ctrl+Shift+V` | 显示 quick · clip |
| `focusMain` | 打开主窗口 | `⌘⇧A` | `Ctrl+Shift+A` | 显示并聚焦 main；允许用户关闭该项 |

设置交互：

- 列表展示当前绑定；「恢复默认」调用 `settings_reset_shortcuts`。
- `v1.0` 可先只读 + 恢复默认（与当前实现对齐）；录制改键作为增强：点击「更改」→ 聆听下一组合键 → 校验保留键 → 保存 → **重新注册全局快捷键**（尽量无需重启；若插件限制则提示重启）。
- 冲突提示文案：「无法注册 {键位}，可能被其他应用占用。可更换快捷键或恢复默认后重试。」

保留键（禁止用户绑定为全局）：`⌘Q` / `Alt+F4` 退出语义、`⌘W` 关闭窗、系统截屏键等。

| 任务 | `⌘3` | `Ctrl+3` | `menu.view.tasks` |
| 记忆 | `⌘4` | `Ctrl+4` | `menu.view.memory` |

| 新建记忆 | `⌥⌘N` | `Ctrl+Alt+N` | `menu.file.new_memory` |
| 设置 | `⌘,` | `Ctrl+,` | `menu.app.settings` / `menu.file.settings` |
| 关闭窗口（隐藏） | `⌘W` | `Ctrl+W` | `menu.file.close_window` |
| 退出应用 | `⌘Q` | `Ctrl+Q` | `menu.app.quit` / `menu.file.quit` |

`⌘N` 语义：始终「新建任务」，不随当前页变成新建记忆（新建记忆用独立键）。页面「+」按钮可按模块默认类型，与菜单可不同。

## 5. 当前选中实体（项目菜单 / 列表）

| 意图 | macOS | Windows | 条件 |
| --- | --- | --- | --- |
| 完成 / 取消完成任务 | `Space` | `Space` | 列表焦点，非输入框 |
| 完成（菜单） | `⌘.` | `Ctrl+.` | 任务选中 |
| 删除… | `⌘⌫` | `Ctrl+Backspace` | 需确认 |
| 再次复制剪切板项 | `⌘⇧C` | `Ctrl+Shift+C` | 可选；无则仅用 Enter（quick） |

多选：`⇧` 范围选、`⌘/Ctrl` 点选；批量完成仍可用 `Space`。

## 7. 快捷窗口 `quick`

### 7.1 各 mode 共用

| 意图 | 键 |
| --- | --- |
| 关闭 | `Esc`（有输入时可先清空再关，见布局文档） |
| 切换 mode | `⌘1` / `⌘2` / `⌘3` 仅在 quick 内映射为 记录/搜索/剪切板；**不**与主窗导航冲突因焦点在 quick |

若实现成本高：用 `Tab` 在分段控件间移动，或 `⌘⇧[` / `⌘⇧]` 循环 mode。

### 7.2 Capture

| 意图 | 键 |
| --- | --- |
| 提交创建 | `⌘Enter` / `Ctrl+Enter` |
| 类型切换 | `⌘⇧↑/↓` 或控件内左右；展示「任务｜提醒｜记忆」 |

### 7.3 Search（含命令面板）

| 意图 | 键 |
| --- | --- |
| 移动选中 | `↑` `↓` |
| 执行命令 / 打开结果 | `Enter` |
| 完成任务（结果为任务时） | `⌘Enter` / `Ctrl+Enter` |
| 延期（结果为任务时） | `⌘⇧Enter` / `Ctrl+Shift+Enter` |

底栏固定提示，与当前实现一致。

### 7.4 Clip

| 意图 | 键 |
| --- | --- |
| 再次复制并隐藏 | `Enter` |
| 尝试直接粘贴 | `⌘Enter` / `Ctrl+Enter` |
| 移动选中 | `↑` `↓` |

无辅助功能权限时：`⌘Enter` 降级为再次复制，或禁用并 toast「已复制，可手动粘贴」。

## 10. 验收标准

1. 四项全局默认在 macOS / Windows 上可唤起对应窗口；冲突时有可见提示。  
2. 帮助或设置中的一览与本文默认表一致。  
3. 输入框内 `Space` / `j` `k` 不触发列表动作。  
4. `⌘W` 隐藏窗口，`⌘Q` 退出进程。  
5. quick search 底栏提示与真实键位一致。  
6. 「恢复默认」后配置与 §3 表一致。
