# 空状态、权限与异常文案设计

## 1. 文档目的

统一空状态、权限缺失、首次引导与常见错误的结构与文案，避免各页语气不一致或只有说明没有动作。与[隐私与数据说明](./privacy-and-data.md)、[UI 布局与交互](./ui-layout-interaction.md)配套。

## 2. 通用结构

### 2.1 空状态 `EmptyState`

```text
标题（一行）
说明（一至两句）
[主操作]  可选次要操作 / 快捷键提示
```

组件约定（相对当前仅 title+body 的实现，应扩展）：

| 属性 | 要求 |
| --- | --- |
| `title` | 必填，陈述现状，不用否定堆砌 |
| `body` | 必填，告诉用户下一步 |
| `primaryAction` | 推荐；无数据时几乎总有 |
| `secondaryAction` | 可选 |
| `hint` | 可选；展示快捷键，如「全局：⌘⇧Space」 |

不使用大插画、表情包或多段营销文案。

### 2.2 权限横幅 `PermissionBanner`

置于页面顶栏下或设置相关区块顶：

```text
[图标] 标题简述
       一句降级说明
       [去系统设置]  [稍后] / [已了解]
```

| 属性 | 说明 |
| --- | --- |
| `severity` | `notification` / `accessibility` / `clipboard_paused` / `backup_failed` 等 |
| 可关闭 | 「稍后」仅本次会话隐藏；严重项（备份失败）不可永久静默 |

### 2.3 语气

- 用「可以 / 请 / 将」，不用责备用户。  
- 权限拒绝说明**失去什么**与**仍能做什么**。  
- 危险操作确认用「删除 / 无法撤销」等明确后果，不用「是否确认？」空壳句。

## 3. 各页空状态文案

### 3.1 今日

| 场景 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 全日无事项 | 今日还没有事项 | 给任务加上今天的截止日期，或新建今日提醒。 | 新建任务 |
| （可选次要） | | | 快速记录 |

当前实现已有标题与说明；应补主操作按钮。

### 3.2 收件箱

| 场景 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 无待整理 | 收件箱为空 | 新任务会先出现在这里。可用全局快捷键随时捕获。 | 新建任务 |
| hint | | 快速记录：{global.quickCapture} | |

### 3.3 任务

| 场景 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 当前清单/筛选无结果 | 没有匹配的任务 | 调整筛选条件，或新建任务。 | 新建任务 / 清除筛选 |
| 清单确为空（无筛选） | 这个清单还是空的 | 把收件箱里的任务移过来，或直接新建。 | 新建任务 |

「清除筛选」仅在存在激活筛选时作为主操作或次要操作。

### 3.4 记忆

| 场景 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 无记忆 | 还没有记忆 | 适合保存短文本、链接和可检索的片段；也可稍后转为任务。 | 新建记忆 |
| hint | | 快速记录里可切换到「记忆」 | |

### 3.5 剪切板

| 场景 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 无历史且采集中 | 暂无剪切板历史 | 复制文本或图片后会出现在这里。密码管理器等来源默认已排除。 | 打开快捷键说明 / 无则省略 |
| 无历史且已暂停 | 暂无剪切板历史 | 采集已暂停，恢复后才会记录新的复制内容。 | 恢复采集 |
| 仅收藏为空 | 暂无收藏 | 在历史条目上点亮星标，收藏不会随过期清理删除。 | 显示全部历史 |

### 3.6 搜索 / 命令面板（quick）

| 场景 | 标题 | 说明 |
| --- | --- | --- |
| 有查询无结果 | 没有找到结果 | 试试更短的关键词，或切换类型筛选。 |
| 无查询 | （不展示全库空状态） | 可显示简短占位：「输入以搜索任务、记忆、剪切板，或执行命令」 |

### 3.7 详情无选中

| 场景 | 标题 | 说明 |
| --- | --- | --- |
| 列表有数据未选中 | 选择一项查看详情 | 也可使用方向键移动选中项。 |
| 列表为空 | 与列表空状态二选一，避免双侧重复 | 优先只显示列表空状态，详情区空白或收起 |

### 3.8 智能列表 / 模板（v1.1）

| 场景 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 智能列表无匹配 | 没有符合条件的项目 | 条件未复制任务，只是筛选视图。 | 打开全部任务 |
| 无模板 | 还没有模板 | 把常用任务、提醒或记忆存成模板，下次一键套用。 | 新建模板 |

## 4. 权限与降级

### 4.1 能力矩阵文案（设置「应用状态」旁）

与隐私文档一致，面向用户的短句：

| 能力 | 已授权 | 未授权 / 不可用 |
| --- | --- | --- |
| 通知 | 到期时将发送系统通知 | 提醒仍出现在「今日」，但不会弹出系统通知。[系统设置] |
| 全局快捷键 | 后台亦可唤起 | 注册失败或冲突：请改键或用托盘。[快捷键设置] |
| 剪切板读取 | 正在监听文本/图片变化 | 无法读取时历史不更新；可检查系统隐私设置 |
| 直接粘贴 | 可用「直接粘贴」 | 请用「再次复制」后手动粘贴。[系统设置] |
| 开机启动 | 登录后自动运行 | 需手动打开应用 |
| 托盘 | 正常 | 若托盘被系统隐藏，请从启动器打开应用 |

### 4.2 横幅触发

| 触发 | 标题 | 说明 | 主操作 |
| --- | --- | --- | --- |
| 首次创建提醒且通知未授权 | 未开启通知 | 到时不会弹出系统通知，「今日」里仍看得到提醒。 | 开启通知 |
| 使用直接粘贴失败/未授权 | 无法直接粘贴 | 内容已复制到系统剪切板时请到目标处粘贴；或授予辅助功能权限。 | 系统设置 |
| 用户暂停采集 | 剪切板采集已暂停 | 不会记录新的复制内容；历史仍可浏览。 | 恢复采集 |
| 自动备份失败 | 自动备份失败 | {简短错误原因}。数据仍在本地，但暂时缺少新的备份保护。 | 立即备份 / 查看设置 |
| 迁移失败 | （全页阻塞，非横幅） | 见 §6 | |

同一会话同类横幅只出现一次；设置页始终显示真实状态。

### 4.3 首次启动 `OnboardingOverlay`

保持现有结构，文案定稿如下：

**标题：** 欢迎使用工作台  

**导语：** 这是一个本地优先的个人工作台。任务、提醒、记忆和剪切板都保存在本机，可完全离线使用。

**要点：**

1. 关闭主窗口会隐藏到托盘，不会退出；提醒与剪切板采集继续运行。  
2. 通知权限用于到期提醒；拒绝后提醒仍会出现在「今日」，但不弹系统通知。  
3. 剪切板可随时暂停；直接粘贴需要辅助功能权限，否则请用「再次复制」。  
4. 请定期导出，或依赖启动时自动备份，保护个人数据。  

**按钮：** 「先试试快速记录」 | 「开始使用」

不在首屏强求授权；进入「今日」后若用户添加提醒再请求通知更合适。

## 5. 确认对话框文案

| 场景 | 标题 | 正文 | 主按钮（危险） | 次要 |
| --- | --- | --- | --- | --- |
| 删除任务 | 删除任务？ | 将删除「{标题}」。此操作无法撤销。 | 删除 | 取消 |
| 删除记忆 | 删除记忆？ | 将删除「{标题}」。已转换出的任务不会一并删除。 | 删除 | 取消 |
| 删除剪切板项 | 删除这条记录？ | 仅从历史中移除，不影响系统当前剪切板内容。 | 删除 | 取消 |
| 清空非收藏 | 清空剪切板历史？ | 将删除所有未收藏条目。收藏的记录会保留。 | 清空 | 取消 |
| 导入覆盖 | 导入数据？ | 将按导入内容写入本地数据。建议先导出当前数据作为备份。 | 继续导入 | 取消 |
| 从备份恢复 | 从备份恢复？ | 当前数据库会被替换为所选备份。请确认已了解风险。 | 恢复 | 取消 |

省略号：菜单项引发确认时，菜单文案带 `…`；对话框标题用问号句。

## 6. 阻塞与严重错误（全页）

| 场景 | 标题 | 说明 | 操作 |
| --- | --- | --- | --- |
| 数据库迁移失败 | 无法升级本地数据 | 已停止写入以免损坏。可尝试从最近备份恢复，或导出诊断信息（不含正文）。 | 恢复备份 / 打开数据目录 / 退出 |
| 磁盘空间不足 | 磁盘空间不足 | 无法保存新的更改或备份。请腾出空间后重试。 | 重试 / 打开数据目录 |
| 后端无法连接 | 无法连接本地服务 | 请尝试重启应用。若反复出现，请查看日志目录。 | 重试 / 退出 |

## 7. Toast / 行内反馈（短）

| 事件 | 文案 |
| --- | --- |
| 任务已完成 | 已完成 · 撤销 |
| 已复制 | 已复制 |
| 已暂停采集 | 剪切板采集已暂停 |
| 已恢复采集 | 剪切板采集已恢复 |
| 已保存为记忆 | 已保存为记忆 · 查看 |
| 已转为任务 | 已创建任务 · 查看 |
| 备份成功 | 备份完成 |
| 导出成功 | 导出完成 |
| 全局快捷键冲突 | 快捷键注册失败，请到设置中调整 |

撤销类 toast 展示 5–8 秒；无撤销则 2–3 秒。

## 8. 加载与占位

- 列表首屏：`加载中…` 或骨架行（等高防跳动）。  
- 详情：字段级 skeleton，避免整栏闪白。  
- 搜索：输入防抖；无结果用 §3.6，不用转圈遮挡已有结果。

## 9. 与实现的缺口

| 项 | 现状 | 目标 |
| --- | --- | --- |
| `EmptyState` | 仅标题+说明 | 支持主/次操作与 hint |
| `PermissionBanner` | 未独立组件 | 今日/剪切板/设置复用 |
| 各页空状态 CTA | 多缺按钮 | 按 §3 补齐 |
| 确认框文案 | 分散 | 按 §5 收敛常量 |
| 备份失败提示 | 设置页有 | 主窗亦可横幅（不可静默） |

## 10. 验收标准

1. 五个一级页在真空数据下均有可读空状态，且至少一项带主操作（剪切板「采集中」可无按钮）。  
2. 通知与辅助功能拒绝后，设置与相关横幅能说清降级路径。  
3. 删除/清空/恢复类确认含后果说明。  
4. 备份失败有可见提示，不依赖用户主动打开设置。  
5. 首次引导可跳过强授权，要点与隐私文档不矛盾。  
6. Toast 含「查看」「撤销」时能导航或回滚对应动作。
