# Trove v2.5.1

界面一致性版本：原生表单控件全量替换为设计系统组件，视觉与主题令牌完全统一。

## 界面统一

- 下拉选择、复选框、单选框、多行输入等原生控件全部替换为设计系统组件（Select / Checkbox / Radio / Textarea）
- 圆角、边框、配色、焦点环统一走主题令牌——**深色模式下控件不再与界面风格违和**
- 复选框 / 单选框使用主题强调色（accent），选中态更清晰
- 覆盖范围：设置、任务、看板、记忆、剪贴板、快速搜索、专注模式等全部界面

## 内部改进

- 端到端连接层加固：tauri-driver 偶发瞬态连接错误自动重试（质量基础设施）
- CI 升级到 Node 24 运行时的 GitHub Actions 大版本（清除弃用告警）

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 纯界面与基础设施变更，不改变任何功能行为与数据
