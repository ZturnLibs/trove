# Trove v2.4.1

修复版本：**剪切板与全应用缩略图图片无法显示**的问题。

## 修复

- **图片不显示**（v1.2 起的存量缺陷）：缩略图接口返回的载荷带了 `data:image/png;base64,` 前缀，而前端所有消费点统一自行拼同款前缀——双重前缀使 data URL 无效，图片永远渲染不出来。受影响面：剪切板列表与详情、统一搜索结果、任务/记忆附件区、专注页关联资产。现接口改回裸 base64（前端契约本意），以上位置图片全部恢复正常。

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 存量图片的缩略图文件完好，升级后立即恢复显示，无需任何操作
