# Trove v2.0.0

可控智能辅助：AI 作为任务、记忆、搜索流程中的辅助能力——**建议必带来源、修改必须经确认、每个功能可单独关闭**；AI 关闭或不可用时，全部既有功能不受任何影响。数据库 schema 升至 **v21**（迁移 0019–0021）；升级时会自动迁移并备份。

## 新功能（智能辅助）

> 配置入口：设置 → 智能辅助（模式：关闭（默认）/ 本地 Ollama / 自定义远程）。使用说明与数据边界见 [ai-assist.md](../ai-assist.md)。

### 长文本提取任务

- 记忆详情「提取任务（AI）」：从会议记录/邮件等长文本识别候选任务，展示原文摘录供核对
- 模糊日期标记「待确认」，创建时**不猜测填入**
- 勾选确认后才创建；正文自动附来源引用与 EntityLink 审计

### 每周回顾 AI 摘要

- 把本周确定性统计组织成一段温和中文小结（≤200 字，禁评价/打分/催促）
- 摘要旁数字徽标始终来自本地查询，「以徽标为准」；可重新生成或忽略

### 相关内容建议

- 任务详情「寻找相关内容」：AI 从本地检索候选中挑选，每条附一句话理由与摘录
- **关联**才写 EntityLink（可解除）；**不相关**记住拒绝、之后不再推荐

### 今日工作建议

- 今日页「获取今日建议」：从逾期+今日到期（排除已在重点/等待）挑 1–3 项，理由基于确定性特征
- **加入重点**完全由你决定（与手动加入一样可撤销）；跳过当日不再推荐；建议跨天自动失效

### 任务检查项（非 AI）

- 任务详情「检查项」：回车追加、勾选、行内编辑、排序、两步删除
- 任务行显示 `2/5` 进度徽标；完成任务后冻结只读；勾满**不**自动完成任务
- 检查项内容参与任务搜索（按子条目可搜到任务）

### AI 任务拆分

- 「AI 拆分」：根据任务说明生成 3–8 条候选检查项，每条附原文依据片段
- 无依据的生成项自动丢弃；**不创建新任务、不改原任务内容**

### 语义检索

- 设置页开启 + embedding 模型（如 `nomic-embed-text`）→ 重建本地向量索引
- 全局搜索新增「语义匹配」分区：换个说法也能找到（如搜「报销流程」命中「差旅票据整理」）
- 索引为派生数据：可排除清单/标签/类型、2 万条上限、可随时清空重建

## 隐私与安全（重点）

- **默认关闭**：未配置时不发起任何模型调用，全部功能按原样运行
- **永不发送**：标记「敏感内容」的记忆、密码管理器来源与排除应用的剪贴板内容（新增记忆「敏感内容」标记）
- API Key 只存本机文件，**不进入数据库、备份、导出与日志**
- 建议历史与语义索引均为派生数据，可一键清空，清空不影响业务数据
- 模型输出经结构化校验（标题回配、依据子串、日期格式），不合格即丢弃，业务数据零污染

## 工程与修复

- 前端新增：设置页智能辅助区块、提取/摘要/相关/建议/拆分面板、语义分区、检查项区

## 升级说明

- 从 v1.x 升级：自动迁移（迁移前自动备份）；旧设置恢复后 AI 保持全部关闭
- 从 v1.4 直接更新即可，无手工步骤
