# Trove v2.7.0 → v2.8.0

任务详情面板与看板卡片的信息密度与交互改进：详情不再挤压内容区，卡片能看更多标题，任务内容支持多行编辑。

## 新增 / 改进

- **详情面板悬浮化**：右侧详情改为悬浮层（带阴影），不再占用列表/看板宽度；未选中任务时面板不渲染，内容区全宽。任务页、看板、收件箱、今日、周回顾统一生效
- **详情面板可关闭**：面板头部 ✕ 或按 `Esc` 关闭（删除确认浮层打开时除外）
- **任务内容多行输入**：面板顶部任务内容输入框随内容自动增高（上限约 6 行），`Shift+Enter` 换行、`Enter` 保存、失焦保存
- **看板卡片标题最多 3 行**：长标题折行显示（`line-clamp-3`），不再单行截断
- **按钮文字防溢出**：按钮全局禁止文字换行与 flex 收缩，修复详情面板头部「开始专注 / 加入重点 / 收件箱」等按钮文字被压成多行的问题

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 纯前端交互改动，CLI 与数据格式不变
