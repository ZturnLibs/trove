# Trove v2.5.0

本版本新增一项可配置效率设置：**今日页底部快速添加的确认键**。

## 今日页快速添加：确认键可配置

- 新增两种确认方式，设置 →「工作节奏」中切换：
  - **Enter 确认添加**（默认，保持既有习惯；⌘/Ctrl+Enter 同样可用）
  - **⌘(Cmd/Ctrl)+Enter 确认添加**——适合习惯在其他输入框用 Enter 换行、或担心误触回车的用户
- 输入框 placeholder 实时提示当前确认方式：`…（Enter 添加）` / `…（⌘↩ 添加）`（mac）/ `…（Ctrl+↩ 添加）`
- 中文输入法组词状态下按 Enter/数字键选词不受影响（组词短路保留）

## 质量改进

- 看板拖拽分发、出牌前校验、详情面板保存三处交互语义抽取为纯函数并以 vitest 覆盖（单元测试 63 → 95）
- e2e：tauri-driver 连接抖动自动重试；看板拖拽/列内排序/URL 直达用例启用（核心流 10 条零跳过）

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 新设置默认值与既有行为一致（Enter 确认），不升级也不受影响
