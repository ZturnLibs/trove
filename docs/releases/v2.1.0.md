# Trove v2.1.0

默认全局快捷键焕新：出厂键位整体迁移到 `⌘⌥`（macOS）/ `Ctrl+Alt`（Windows）修饰组合，避开系统键与高频应用全局键的已知冲突。**从未自定义过快捷键的老用户升级后自动迁移到新默认；自定义过的键位原样保留。**

## 快捷键默认键位更新

| 意图 | 旧默认 | 新默认 |
| --- | --- | --- |
| 快速记录 | `⌘⇧Space` / `Ctrl+Shift+Space` | `⌘⌥Space` / `Ctrl+Alt+Space` |
| 统一搜索 | `⌘⇧F` / `Ctrl+Shift+F` | `⌘⌥F` / `Ctrl+Alt+F` |
| 剪切板历史 | `⌘⇧V` / `Ctrl+Shift+V` | `⌘⌥C` / `Ctrl+Alt+C` |
| 聚焦主窗口 | `⌘⇧A` / `Ctrl+Shift+A` | `⌘⌥T` / `Ctrl+Alt+T` |
| 区域截图 | `⌘⇧6` / `Ctrl+Shift+6` | `⌘⌥X` / `Ctrl+Alt+X` |

规避的已知冲突：

- **微软拼音简繁切换 `Ctrl+Shift+F`**（中文用户高概率撞车）
- **Chrome / Edge 标签页搜索 `Ctrl+Shift+A`**
- 主流应用「无格式粘贴 `Ctrl+Shift+V`」、macOS 剪贴板工具默认键
- Touch Bar 机型系统截图 `⌘⇧6` 及系统截图修饰链 `⌘⇧3/4/5`
- 输入法相关修饰链 `Ctrl+Shift` / `Ctrl+Space` / `⌘Space`（Spotlight）

## 改键录制加固

设置页「更改」录制新键位时，拒绝以下系统保留组合，避免误绑后系统行为被劫持：

- 退出 / 关闭 / 最小化：`⌘Q`、`⌘W`、`⌘M`、`Alt+F4`、`Ctrl+Q/W/M`
- 启动器与输入法：`⌘Space`、`Ctrl+Space`、`⌃⌘Space`（表情与符号面板）
- 系统截图：`⌘⇧3`、`⌘⇧4`、`⌘⇧5`
- 窗口与进程管理：`Alt+Tab`、`Alt+Space`、`Ctrl+Shift+Esc`（任务管理器）、`⌘⌥Esc`（强制退出）
- Windows / Linux 上仅含 Win（Super）键的组合一律拒绝（如 `Win+E`、`Win+D`）

## 升级说明

- 老版本升级：快捷键存储值为出厂默认（未自定义过）时，首次启动自动迁移到新默认并持久化；设置页「恢复默认」同样恢复到新默认。
- 自定义过任一键位的用户**不受影响**，如需换新键位请到 设置 → 快捷键 手动更改。
- 已知取舍：`Ctrl+Alt` 在部分欧洲键盘布局等价 AltGr；`⌘⌥T` 与 Safari「显示标签栏」冲突（应用内键位，低频）。介意者可自行改键。
- 无数据库 schema 变更，无数据迁移风险；本版本不涉及智能辅助行为变化。
