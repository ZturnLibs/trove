# Trove v2.10.0 → v2.11.0

看板与清单管理改进：新建任务置顶所在清单，侧边栏清单支持拖拽排序。

## 新增 / 改进

- **看板新建任务置顶**：列内「＋新建任务」创建后，新任务自动重排到所在清单的最上面，不再掉到列表底部（跨清单场景同样置顶于自身清单）
- **侧边栏清单拖拽排序**：清单行可作为拖拽落点，拖到另一个清单上即完成同级排序（高亮落点提示）；排序持久化，任务页/看板/今日/收件箱的清单下拉与侧边栏顺序一致
- 跨分组拖放语义保留：拖到其他分组的清单上 = 移动到该分组

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 新增只读性 IPC 命令 `task_list_reorder`（仅重写清单 sort_order），CLI 与数据格式不变
