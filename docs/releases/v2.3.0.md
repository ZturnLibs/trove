# Trove v2.3.0

本版本围绕「收尾与效率」：新增每周回顾处理模式，看板交互补全（双击改名、列内排序），CLI/URL Scheme 能力扩展，并落了一套端到端回归网（10 条核心流 CI 全绿）。

## 每周回顾处理模式

每周回顾页新增「开始处理」：把待处理队列变成单条出牌模式，逐条决策、不纠结。

- 四队列出牌：完成 / 归档 / 推迟 / 标记等待，数字键 `1-4` 直选，`Esc` 退出保留会话
- 出牌前自动校验任务状态，已完结任务自动跳过并提示
- 结束展示本次处理统计，与既有「完成回顾」汇总打通

## 看板交互补全

- 卡片**双击标题行内改名**（乐观更新，与任务页同模式）
- **同清单列内拖动排序**：拖卡片到兄弟卡片上即完成排序（sort_order 为清单内维度；完成列按完成时间排序，不支持手动重排）
- 落卡体验修复：失效面收窄至看板查询 + 浮层落位动画，消除落卡卡顿
- 滚动条细窄内衬式美化

## CLI 与 URL Scheme

- `trove-cli export-csv --out <path>`：经运行中的 app 导出任务 CSV（`--json` 可得结构化结果）
- `trove://today` 直达：Linux / Windows 上经单实例转发打开主窗口并跳转今日视图（dev 构建即可用，无需系统注册）

## 质量基础设施：端到端回归网

- 新增 `tauri-driver`（WebDriver）e2e 冒烟：10 条核心用户流（启动渲染 / 收件箱新建 / 完成撤销 / 双击改名 / 跨列拖拽 / 列内排序 / 分组新建 / 页内搜索 / URL 直达 / CLI 导出）在 CI Linux 全绿，**零跳过**
- 数据隔离（每用例独立 `TROVE_DATA_DIR`）、失败自动留证（截图 / DOM / driver 日志 / DB 快照）
- `trove-cli export-csv` 同时作为失败诊断的 DB 快照通道

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 不涉及智能辅助行为变化
