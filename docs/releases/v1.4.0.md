# Trove v1.4.0

自动化与外部集成：同一套动作层供界面、`trove://`、CLI 与快捷指令使用；本地规则可预览、可停用、可追踪。数据库 schema 升至 **v18**（迁移 0017–0018）；升级时会自动迁移并备份。

## 新功能

### 统一动作层

- 内部 `WorkbenchAction` 协议：导航、搜索、创建预览、确认后写入、只读查询
- `trove://` 行为与 v1.3 一致（创建仍须预览确认）
- 详见 [action-layer.md](../action-layer.md)

### 本地 CLI（`trove-cli`）

- `today` / `inbox` / `search` / `create` / `complete` / `query` / `raw`
- `--dry-run`、`--json`；写入须 `--yes`
- 经运行中的应用转发，不直连 SQLite
- 详见 [cli.md](../cli.md)

### 规则自动化

- 触发：创建任务/提醒/记忆、移入清单、加标签、剪切板收藏、提醒触发
- 动作：设优先级、移清单、加标签、置顶记忆、本地通知（不执行任意脚本）
- 全局开关、单条暂停、试运行、执行日志、防递归
- 设置 → 规则自动化；详见 [automation.md](../automation.md)

### macOS 快捷指令

- 通过「运行 Shell 脚本」调用 `trove-cli --json query …`
- 可取今日/逾期/收件箱/记忆/收藏片段
- 详见 [shortcuts.md](../shortcuts.md)

### 任务 CSV 导入导出

- 设置 → 备份与数据 → 任务 CSV
- 导入前预览映射、重复与错误；失败不留半完成数据
- 导入批次可撤销尚未继续修改的条目
- JSON 全量导出仍是无损备份；CSV 不含周期与提醒
- 详见 [csv-import.md](../csv-import.md)

## 升级说明

- 从 `v1.3.x` 升级：自动迁移 0017（规则表）与 0018（导入批次）
- 建议升级前确认备份目录可读（设置 → 健康 / 备份）
- 规则自动化默认开启，可在设置中关闭；关闭后任务/提醒/记忆/剪切板不受影响
- CSV 导入是**追加**任务，不会覆盖现有数据（与 JSON 全量导入不同）
