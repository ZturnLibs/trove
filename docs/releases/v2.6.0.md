# Trove v2.6.0

本版本延续 v2.5.0 的确认键可配置：**看板列内新建任务与设置同步**。

## 看板列内新建：确认键与设置同步

- 看板列内「＋ 新建任务」行内输入的确认键，跟随设置 →「工作节奏」→「今日页底部快速添加的确认方式」：
  - **Enter 确认创建**（默认；⌘/Ctrl+Enter 同样可用）
  - **⌘(Cmd/Ctrl)+Enter 确认创建**——裸 Enter 不再误创建
- 输入框 placeholder 按当前确认方式与平台显示：`标题后 Enter 创建，Esc 关闭` / `标题后 ⌘↩ 创建，Esc 关闭` / `标题后 Ctrl+↩ 创建，Esc 关闭`
- `Esc` 关闭行内输入的行为不变

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 未修改该设置的用户行为不变（仍为 Enter 创建）
