# Trove v2.6.2

修复版本：**任务详情附件「附加图片」后不显示**的问题，并支持多选批量附加。

## 修复

- **附加图片后附件区不显示**：选择器把剪贴板条目 id 误当资产 id 建立附件链接——幽灵链接在展示查询中被静默跳过，附件永不显示。现改传正确的资产 id，选择即出现在附件区。

## 新增

- 附加图片选择器支持**多选**：点选多张（勾选角标提示、已选计数），一键批量附加；已附加过的图片自动隐藏防重复

## 其他

- 后端加固：附件链接创建时校验目标资产存在（防同类幽灵链接再次入库）
- 回归测试：真实资产 → 链接 → 查询命中且缩略图可解析

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- macOS 用户：本版本的应用内更新依赖 macOS 构建产物（GitHub runner 容量恢复后自动补齐）；如需立即升级，可从 GitHub Release 手动下载安装包
