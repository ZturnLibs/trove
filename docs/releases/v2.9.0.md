# Trove v2.8.0 → v2.9.0

附件图片支持原图预览，悬浮详情栏支持拖拽调整宽度。

## 新增

- **附件图片预览**：详情面板附件区的缩略图点击即进入原图灯箱预览（新增 `asset_read_data` 命令返回完整原图，非放大缩略图）；`Esc`、点击遮罩或右上 ✕ 关闭
- **详情栏拖拽调宽**：悬浮详情栏左缘可拖拽调整宽度（280–640px，随视口自适应上限），宽度持久化，重开应用保持；任务页、看板、收件箱、今日、周回顾统一生效

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 新增一个只读 IPC 命令（`asset_read_data`），CLI 与数据格式不变
