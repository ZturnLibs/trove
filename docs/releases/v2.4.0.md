# Trove v2.4.0

本版本的两大主线：**Linux 正式加入官方发布渠道**，统一搜索获得类型筛选。

## Linux 官方发布通道（首秀）

- GitHub Release 新增 Linux 构建产物：`.deb` 与 `.AppImage`
- 应用内更新检查（updater）覆盖 Linux：`latest.json` 含 Linux 平台条目
- 质量背书：端到端回归网（10 条核心用户流）本就在 ubuntu CI 上全绿，Linux 产物与 CI 同源

## 统一搜索类型筛选

- 快捷搜索（`⌘⌥F` / `Ctrl+Alt+F`）新增筛选条：**全部 / 任务 / 提醒 / 记忆 / 剪切板**
- 筛选在服务端执行（`search_query` 类型参数），结果与语义匹配同步过滤
- 切换筛选自动重置键盘选中项，方向键体验不变

## 端到端回归网增强

- 新启用 3 条用例：看板跨列拖拽、看板列内排序、URL Scheme 直达——核心流 10 条**全部可执行、零跳过**
- 修复 `wait_for` 对 Stale element 的误报抖动（此前偶发让整个 e2e job 失败）
- 前端纯决策内核（看板拖拽分发 / 出牌校验 / 详情面板保存）抽取为可测纯函数，单元测试 63 → 87

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- Linux 首次安装：`.deb` 直接安装；`.AppImage` 需要系统 FUSE（多数发行版自带）
- 升级用户：应用内「检查更新」即可获取对应平台升级包
