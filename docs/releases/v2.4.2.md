# Trove v2.4.2

修复版本：**macOS 应用内升级后启动白屏**的问题。

## 修复

- **macOS 升级后白屏**：应用内更新完成后的自动重启，原先直接 spawn 新二进制（不经 LaunchServices），新实例未被系统注册/激活——WebView 页面被判为不可见，WebProcess 启动约 13 秒后挂起，窗口内容永不渲染（白屏）。现重启改为经 LaunchServices `open` 启动应用包：新实例正常注册、激活并渲染。
- 该问题影响所有通过应用内「检查更新」升级到新版本的 macOS 用户；从 GitHub Release 手动下载安装（拖入 /Applications）的路径不受影响。

## 其他

- 端到端连接层加固：tauri-driver 偶发瞬态连接错误不再导致整条用例判死（质量基础设施）。
- CI 升级到 Node 24 运行时的 GitHub Actions 大版本（清除弃用告警）。

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- **macOS 升级提示**：本次升级请从 GitHub Release 手动下载安装（或在当前白屏/正常窗口内检查更新后，若重启后白屏，从「应用程序」文件夹或 Dock 再打开一次即为修复后版本；v2.4.2 之后的升级将不再出现该问题）
