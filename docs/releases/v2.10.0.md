# Trove v2.9.0 → v2.10.0

快速添加支持多行批量创建，剪切板详情可关闭。

## 新增

- **多行输入批量创建任务**：今日页快速添加、看板列内新建、快速记录窗（⌘↩）的任务输入框升级为自动增高多行输入（`Shift+Enter` 换行，粘贴多行文本同样支持）。提交时若检测到多行内容，弹窗询问「创建 1 条任务 / 创建 N 条任务」：
  - 创建 1 条：整段文本作为一条任务（保留换行，配合详情面板多行内容框编辑）
  - 创建 N 条：每行一条，沿用当前清单与标签；看板「进行中」列创建自动置 doing
  - 预览区展示待创建的行内容（最多 5 行，`Esc` 取消）

## 修复

- **剪切板详情 ✕ 无法关闭**：点 ✕ 清空选中后被「自动选中第一条」逻辑立即选回，面板关不上；已移除自动选中——选中项被删除或被筛选过滤时仅清空选中，详情默认收起

## 升级说明

- 无数据库 schema 变更，无数据迁移风险
- 纯前端交互改动，CLI 与数据格式不变
