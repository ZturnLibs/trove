# Trove v1.3.0

自 v1.2.7 起补齐 **v1.3 竞品差距路线图**（Wave A/B/C），聚焦工作节奏（GTD/复盘）与捕获闭环。数据库 schema 升至 **v16**（迁移 0010–0016）；首次启动或升级时会自动迁移并备份。

## 新功能

### 工作节奏（Wave A）

- **GTD 工作流状态**：任务可标记「等待 / 推迟」；今日页分区展示等待跟进；推迟预设与 `DeferPicker`
- **专注模式**：今日重点拖放、专注会话计时、完成/保留/放弃结果；全局 Focus 浮层
- **每日收尾**：向导式收尾流程 + 摘要对话框（完成数、提醒数、重点处理率）
- **每周回顾**：独立回顾页，快照未完成项与统计，完成后归档记录

### 差异化（Wave B）

- **健康仪表盘**（设置 → 健康）：数据库/备份/提醒/任务/剪切板概览；存储 GC 预览与手动清理
- **记忆双链**：`[[标题]]` 维基链接解析、提及计数与反向链接
- **剪切板智能动作**：URL/日期/代码等分类提示；相似任务匹配；一键转任务草稿
- **今日智能排序**：今日到期任务排序建议 + 采纳；可在设置中关闭

### 生态与捕获（Wave C）

- **托盘今日面板**：左键弹出锚定弹层，可完成/推迟/打开详情，数字与今日页一致
- **QuickWindow NLP 加深**：`#标签`、`p1/p2/p3`、相对日期与重复规则；⌘1–5 字段跳转；搜索模式命令/内容分区
- **`trove://` URL Scheme**：`today` / `inbox` / `search?q=` / `create?type=…`（创建须确认）；详见 [url-scheme.md](../url-scheme.md)
- **捕获余留**：macOS 区域截图（⌘⇧6）→ 剪切板+OCR；任务/记忆文件引用（macOS 安全书签）；浏览器扩展 follow-up 文档

## 改进

- 任务行与详情：等待区、文件引用区、延期埋点
- 设置页：快速记录语法速查、截图快捷键、今日智能排序开关
- 测试：Rust 93 项、前端 42 项单元测试

## 升级说明

- 从 v1.2.x 升级：**自动迁移**，建议在升级前确认备份目录可读（健康页可查看）
- 托盘 **左键** 行为变更：由「快速记录」改为「今日面板」；快速记录仍可通过托盘菜单与全局快捷键唤起
- Windows **区域截图** 暂不支持（会返回友好错误，不 crash）
- **文件引用** 当前以 macOS 安全书签为主；Windows 路径存储可用，Reveal/Open 行为因平台而异
