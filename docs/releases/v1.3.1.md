# Trove v1.3.1

`v1.3.0` 后的 **文档补丁** 版本：同步托盘「今日面板」与相关设计文档，无数据库 schema 变更、无新迁移。

## 变更

- **文档**：`app-menu-design.md` 更新托盘左键/次键手势（左键 → 今日面板弹层；macOS ⌃ 点击 / Windows 右键 → 菜单），新增 §4.4 今日面板弹层说明
- **文档**：`technical-design.md` §7.3 对齐 `tray-today` WebView 弹层与原生菜单分工
- **文档**：与 `ui-layout-interaction.md` §4.3 保持一致

## 升级说明

- 从 `v1.3.0` 升级：**无功能差异**，可不升级；若仅关心文档，直接阅读仓库文档即可
- 应用内「检查更新」会收到同版本号的构建产物（版本号递增便于维护者追踪）
