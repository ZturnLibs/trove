# 隐私与数据说明

工作台是本地优先应用：核心业务数据保存在本机，不依赖网络，也不把任务、提醒、记忆或剪切板正文上传到服务器。

## 数据存放位置

- SQLite 数据库：应用数据目录下的 `workbench.db`
- 自动/手动备份：同目录下的 `backups/`
- 日志：仅记录诊断信息，**不包含**用户正文或剪切板内容

可在「设置 → 应用状态」查看当前数据库路径。

## 权限用途

| 能力 | 用途 | 拒绝后的降级 |
| --- | --- | --- |
| 通知 | 到期提醒弹出系统通知 | 提醒仍写入「今日」，但不弹通知 |
| 全局快捷键 | 唤起快速记录 / 搜索 / 剪切板 | 仍可通过托盘与主窗口操作 |
| 剪切板读取 | 记录文本历史 | 可暂停采集；历史仍可浏览 |
| 辅助功能（macOS） | 直接粘贴 | 「再次复制」始终可用 |
| 开机启动 | 登录后后台运行 | 手动打开应用即可 |

## 剪切板隐私

- 默认只采集文本，不做联网识别。
- 可一键暂停/恢复。
- 默认排除常见密码管理器，并可自定义排除列表。
- 收藏条目不参与自动过期。
- **无法**仅凭文本内容准确识别全部密码、验证码或密钥；敏感场景请暂停采集。

## 备份与恢复

- 启动时可自动备份，并按保留数量轮转。
- 数据库升级前会先生成可恢复备份；失败则中止迁移。
- 支持完整 JSON 导出/导入，以及从本地 `.db` 备份恢复。
- 自动备份失败时，主窗口会显示可见提示，不会静默丢失保护能力。

## 你的选择

你可以随时：

1. 暂停剪切板记录  
2. 关闭开机启动  
3. 导出全部数据并自行保管  
4. 删除本机应用数据目录中的数据库与备份  

第一版不提供跨设备同步或云备份。若后续引入联网能力，会单独说明并默认关闭。
