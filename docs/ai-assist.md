## 1. 你能配置什么

设置页 → **智能辅助**：

| 模式 | 说明 |
| --- | --- |
| 关闭（默认） | 不发起任何模型调用，全部功能按原样运行 |
| 本地 Ollama | 连接本机 Ollama（默认 `http://localhost:11434`），需填写模型名（如 `qwen3:4b`） |
| 自定义远程 | 任意 OpenAI 兼容接口（含 `/v1`）+ 模型名 + API Key |

- **测试连接**：按当前填写内容即时探活，失败会给出分级提示（缺地址/缺模型/缺密钥/不可达）。
- **功能开关**：五项功能逐项可关，默认全部关闭；各项随后续版本开放。
- **建议历史**：查看/清空建议台账。清空只删除派生数据，不影响任何任务、记忆、提醒。

## 2. 数据边界（冻结）

**永远不会发送**：

- 标记「敏感内容」的记忆（记忆编辑区勾选）；
- 来自密码管理器（1Password、Bitwarden 等）或你手动排除的应用的剪贴板内容；
- API Key 本身（仅保存在本机 `ai_provider_key` 文件，不进入数据库、备份与导出）。

**仅当你选择远程模式时**才可能发送：所选功能所需的最小上下文（任务/记忆标题与正文片段、OCR 文本），发送前经统一过滤。

**始终留在本地**：功能开关判断、敏感过滤、结构化校验、统计数字、建议合并排序。

## 3. 使用：长文本提取任务（已开放）

在记忆详情打开一条较长的记录（会议纪要、邮件摘抄等），点击 **提取任务（AI）**：

1. AI 识别候选任务，展示为草稿列表，每条附**原文摘录**供核对；
2. 日期不确定的条目会标记「日期待确认」——创建时**不会**猜测填入，可创建后在任务里补；
3. 勾选要创建的条目 → **创建选中任务**，任务进入收件箱，正文自动附来源引用；
4. 都不合适可整体忽略（之后可重新提取）。

前提：设置页开启智能辅助并打开「长文本提取任务草稿」开关；标记「敏感内容」的记忆不会出现在该入口中。

## 4. 使用：每周回顾摘要（已开放）

每周回顾页顶部，开启功能后可点 **生成 AI 摘要**：

- 摘要把本周的确定性统计（收件箱/逾期/等待/完成等）组织成一段温和的中文小结；
- 摘要旁边的数字徽标始终来自本地查询，**以上方徽标为准**；模型不产生任何数字；
- 可随时重新生成或忽略；完成本次回顾后未处理的摘要会自动清理。

## 5. 使用：相关内容建议（已开放）

任务详情面板的「相关内容建议（AI）」区：

- 点击 **寻找相关内容**，AI 从本地检索到的记忆/剪贴板内容中挑选可能相关的条目，每条附一句话理由与原文摘录；
- **关联** 才会建立正式关联（可在关联区看到、可解除）；**不相关** 会记住这次拒绝，之后不再重复推荐该内容；
- 未找到相关内容时如实提示，不会硬凑。

## 6. 可靠性承诺

- AI 关闭、未配置或调用失败时，全部既有功能不受任何影响；
- 模型输出必须通过结构化校验（JSON schema、日期格式或显式 `ambiguous` 标记、原文引用非空），不合格即丢弃并记录审计行，**业务数据零污染**；
- 所有统计数字由确定性查询产生，模型只负责组织文字；
- 每条建议携带来源引用，可跳转原文；任何写入动作必须经你逐项确认。

## 7. 常见问题

**Q：Ollama 怎么装？** 参考 [ollama.com](https://ollama.com)（`brew install ollama` / 官网安装包），安装后 `ollama pull qwen3:4b` 拉取模型，再回到设置页测试连接。

**Q：清空建议历史会删掉什么？** 只删 `ai_suggestions` 台账（含已接受建议的记录），不会撤销已创建的任务/记忆——那些是你的业务数据。

**Q：怎么彻底移除 AI 痕迹？** 模式切回「关闭」→ 清除 API Key → 清空建议历史。无需重启。
